# Md Wahidur Rahman - GitHub Pages Website

This package contains a simple academic website ready to publish with **GitHub Pages**.

## Included updates
- Profile-based academic homepage
- **CV in PDF format** (`assets/Md_Wahidur_Rahman_CV.pdf`)
- Research interests section
- **Projects section**
- Contact links (LinkedIn, ResearchGate, email)

## How to publish
1. Create a GitHub repository named **YOUR-USERNAME.github.io**
2. Upload all files from this folder to the repository root
3. Wait about 1–3 minutes
4. Visit `https://YOUR-USERNAME.github.io`

## Easy customization
- Replace `assets/profile.jpg` with another photo if you want
- Update text in `index.html`
- Update site design in `styles.css`

## Main files
- `index.html` → website content
- `styles.css` → website styling
- `assets/Md_Wahidur_Rahman_CV.pdf` → downloadable PDF CV
- `assets/profile.jpg` → profile photo
